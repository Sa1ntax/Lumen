# Lumen

Динамический остров для Windows. Своё окно поверх рабочего стола, без браузера.

## Скачать

Готовая программа: [Lumen-Windows.zip](https://github.com/Sa1ntax/Lumen/releases/latest/download/Lumen-Windows.zip)

## Установка

1. Скачай `Lumen-Windows.zip`.
2. Распакуй в папку, например `C:\Lumen`. Не запускай из открытого архива.
3. Запусти `Lumen.exe`.
4. Если Windows спросит, нажми **Подробнее**, затем **Выполнить в любом случае**.

Остров висит сверху по центру. Клик мимо него проходит в окна под ним. Наведи курсор, чтобы раскрыть: плеер, фокус, уведомление, игра, переключатели. Если в Spotify или другом плеере что-то играет, остров показывает этот трек и управляет им.

Закрыть: правый клик по значку Lumen у часов, пункт **Выход**. Там же можно включить запуск вместе с Windows.
